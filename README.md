# 댕순 (daengsoon) — 같이 보는 물멍·불멍

모르는 사람들과 **같은 모닥불**을 바라보는 곳.
누군가 장작을 넣으면 모두의 화면에서 불이 커지고, "지금 N명이 함께 보고 있어요"가 실시간으로 바뀝니다.

## 구조 한눈에 보기

```
daengsoon/
├─ apps/
│  ├─ client/   브라우저에서 돌아가는 화면 (Vite + TypeScript + Canvas)
│  └─ server/   접속자를 연결해 주는 서버 (Node.js + WebSocket)
└─ packages/
   └─ shared/   양쪽이 주고받는 메시지의 "약속"(타입). 한 곳에서 정의해 둘 다 씁니다.
```

비유하면 **서버는 캠프장 관리인**입니다. 모닥불(상태)은 관리인이 관리하고,
손님(브라우저)은 "장작 넣을게요"라고 말만 합니다. 관리인이 장작을 넣고 모든 손님에게 "불 커졌어요"라고 알립니다.
그래서 모두가 항상 같은 불을 봅니다.

- **WebSocket**: HTTP가 편지(보내고 답장 기다림)라면 WebSocket은 전화(한 번 연결하면 양쪽이 아무 때나 말함).
  동시접속의 핵심입니다.
- **Canvas**: 브라우저 안의 그림판. 불과 물은 영상 파일이 아니라 매 프레임 코드로 그립니다.
- **Web Audio API**: 브라우저 안의 믹싱 콘솔. 소리도 파일 없이 합성합니다(저작권 걱정 없음).

## 실행

```bash
pnpm install
pnpm dev        # 서버(8787) + 화면(5173) 동시에 켜짐 → http://localhost:5173
```

브라우저 창을 두 개 열어 보세요. 한쪽에서 장작을 넣으면 다른 쪽에서도 불이 커집니다.

```bash
pnpm build      # 배포용 빌드
pnpm start      # 서버 하나가 화면과 WebSocket을 모두 서빙 → http://localhost:8787
```

## 배포

`Dockerfile`이 있어 Fly.io, Railway, Render 등 **긴 연결을 유지할 수 있는** 곳이면 어디든 올라갑니다.
(Vercel 같은 서버리스는 WebSocket 연결을 오래 못 잡아두므로 맞지 않습니다.)
